# eddyndumia.github.io

This is the primary portfolio site. Its GitHub Pages workflow builds the latest Hugo source from [`Eddy-Ndumia-Personal-Portfolio`](https://github.com/eddyndumia/Eddy-Ndumia-Personal-Portfolio), using `https://eddyndumia.github.io/` as the base URL.

The Netlify site `ndumia.netlify.app` builds from the same source repository and publishes the same pages.
